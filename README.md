# Albert a Hviezdna záhrada

Pokojná počítačová hra na mieru pre päťročné dieťa: krátke výpravy, záhradka pri domčeku a jasný koniec každého hrania.

- [NAVRH.md](NAVRH.md): návrh hry (príbeh, výpravy, ochrana pred „ešte chvíľku“, ako hru uviesť a prispôsobiť)
- [PROMPT.md](PROMPT.md): prompt na skopírovanie do Claude, podľa ktorého Claude hru postaví

Hra bude jeden súbor `index.html`, ktorý sa otvorí dvojklikom v prehliadači, bez internetu a bez inštalácie.
